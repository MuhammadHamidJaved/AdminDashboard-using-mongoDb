# Full Stack React + Vite + Express App

## Structure
- `client/`: React frontend (Vite)
- `server/`: Express backend (Node.js)

## Getting Started

### Frontend
1. `cd client`
2. `npm install`
3. `npm run dev`

### Backend
1. `cd server`
2. `npm install`
3. `npm run dev`

## API Example
- Backend exposes `/api` endpoint.
- Frontend can fetch from `http://localhost:5000/api`.
